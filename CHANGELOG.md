# Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]

### Added
- Kotlin Multiplatform project scaffold (Android and iOS)
- Multi-brand camera APIs: Sony, Canon, Nikon, Fujifilm, Panasonic, OM System
- PTP/IP and JSON-RPC protocol implementations
- QR code and NFC pairing flows
- Live view streaming and capture UI
- Exposure controls (ISO, shutter speed, aperture, EV compensation)
- Camera overlay system (grid, histogram, zebra, focus peaking, safe zones)
- Media library with browse, download, share, and delete
- Google Play Billing integration with trial, monthly, and lifetime plans
- iOS actual declarations and StoreKit integration
- CI/CD workflows for Android and iOS builds
- GitHub community files (contributing guide, security policy, code of conduct)
